# 포트폴리오 영상 촬영

`Assets/Scenes/ShooterInGame_Portfolio.unity`를 열고 평소처럼 **게임 시작**을 누른다. 과녁, 제한시간, 몬스터, 포탈과 사격은 본 게임과 동일하게 동작한다.

- 기본 배치: 실제 플레이 화면이 전체를 차지하고, 오른쪽 아래에 몬스터 위치와 추적 경로가 보이는 작은 전술 지도를 표시한다.
- `F6`: 지도를 전체 화면으로 확대하고 실제 플레이를 오른쪽 아래에 배치하거나 다시 되돌린다.
- `F7`: 지도 위 이름표를 숨기거나 다시 표시한다.
- 오른쪽 위 후방 화면은 본 게임 씬에도 적용되어 있다. 플레이 중 계속 표시되며 가까운 몬스터가 후방 화면에 들어오면 테두리가 반응한다. 조준·사격 방향에는 영향을 주지 않는다.

지도 색: **노랑 = 플레이어**(바라보는 방향 막대 포함), 빨강 = 추격, 청록·보라 = 우회(길목 막기), 파랑 = 복귀(흐린 선), 초록 = 순찰, 주황 = 수색, 회색 = 멈춤, 깜빡이는 흰색 = 감전. 몬스터 이름표에는 지금 하는 일(추격 · 협공 추격 · 해산 → 우회 · 해산 → 복귀 · 놓침 등)이 붙는다.

- **판단 기록**: 지도 위 상자에 최근 판단 5줄이 7초 동안 표시된다. 예) "B: 발견 → 사냥 시작", "C: A와 같은 길로 추격 중 → 다른 길로 우회 (약 5초)", "감독: 8초 동안 못 찾음 → 사냥 끝, 복귀".
- **소리**: 좌클릭하면 쏜 자리에서 소리 반경만큼 원이 퍼진다. 들은 몬스터가 있으면 노란 원과 그 몬스터로 이어지는 선, 이름표의 "들음!"이 뜬다. 아무도 못 들으면 회색 원과 "아무도 못 들음"이 뜬다. 과녁 파괴음도 같은 방식이고, 사냥 중에는 "무시됨"으로 표시된다.

영상에서는 기본 배치로 과녁을 찾아 이동하고 발사한 뒤 지도의 경로가 갈라지는 장면과 후방의 추격자를 함께 담는다. `F6`으로 지도를 확대하면 협공 경로를 자세히 설명할 수 있다.
