# 준비 이동·지원 합류 폴리싱 (2026-09-21)

기준 사람 플레이: `2026-09-20_23-22-30_c7f603`. 의도는 연결된 서로 다른 통로에서 동시에 압박하고, 좁은 길에서는 줄서기를 만들지 않는 것이다. 텔레포트 폐기, 기존 근접 추격자 유지, 순찰 구역 스왑, 기절/시야 차단을 통한 도주를 유지한다.

## 적용

1. **준비 몬스터의 정체를 별도로 추적한다.** 실제 위치가 0.75m 이상 움직여야 정체 시간이 초기화된다. 매번 경로를 다시 배정하는 것으로 정체 시간을 초기화하지 않는다. 최종 대기 지점 도착, 별도 경로 없음, 이동 중, 이동 정체를 이벤트와 10Hz 샘플에 구분해서 기록한다. 중간 모퉁이는 최종 도착으로 표시하지 않는다.
2. **2.5초 이상 진행이 없으면 다른 후보를 탐색한다.** 기본 후보 10~35m/16개에서 확장 후보 10~50m/24개로 넓힌다. 현재 위치에서 3m 이내인 후보를 제외하고, 가까운 후보 8개와 나머지 영역에 분산한 후보를 확인한다. 연결 경로·기존 접근 경로 중복·플레이어를 가로지르는 경로 금지 검사는 그대로 유지한다. 확장 탐색 실패 시 정상 범위의 유효한 경로를 다시 확인하고, 그것도 없으면 대기한다. 순간이동하거나 벽을 통과하지 않는다.
3. **확장 탐색을 분산한다.** 한 계획에서 최대 한 마리만 확장하며 오래 정체한 순서로 기회를 준다. 같은 몬스터의 확장 재시도 간격은 최소 2.5초다. 기존 계획 갱신 주기를 사용하여 대기 몬스터가 매 프레임 재계획을 유발하지 않게 한다. 점프·기절 중 정체 시간을 누적하지 않는다.
4. **지원 점수와 시간 제한에 도착 예상 시간을 사용한다.** 기존의 전체 거리÷최대속도 대신, 경로를 5m 이하 간격으로 나누어 목적지 근처 감속을 적용하고 모퉁이 회전 비용을 더한다. 추정치는 보장 도착 시각이 아니며, 가속·회피·점프를 모두 시뮬레이션하지 않는다. 이 예상 시간이 기존 `detourTimeLimit`을 넘는 지원 경로는 제외한다. 주 추격자 보호와 통로 중복 금지가 시간 점수보다 우선한다.
5. **줄서기 해제 직후 재합류를 막는다.** 기존 1.2초 줄서기 차단 시간에는 준비 경로도 다시 배정하지 않고 잠시 대기한다. 그 후 별도 경로를 탐색한다.

추격 속도, 몬스터 수, 체력, 기절 시간, 기억 시간, 과녁/포탈 목표 수는 이번에 변경하지 않았다. 근거 없는 실시간 플레이어 위치를 새로 전달하지 않는다. 새로운 사운드 에셋은 이번 범위에 포함하지 않았다.

## 남은 확인

실제 사람이 이번 버전을 플레이한 기록은 아직 없다. 다음 기록에서 준비 정체 시간, 두 몬스터의 실제 근거리 합류, 기절 후 확보하는 여유, 긴 압박 공백을 함께 비교한다. 지원 시간 제한 때문에 늦는 몬스터가 준비 역할로 남는 경우가 생긴다. 단순한 활성 추격자 수 감소를 퇴보로 단정하지 말고 실제 합류를 확인한다.
